# UI 与体验设计

- 状态：有效设计，已实现本地开发版；真实 X 与人工体验验收未完成。
- 依据：[v1 规格](../../specs/2026-09-13-topic-hunter-v1.md)。本文件是详细设计 Token 的唯一来源。
- 方向：简洁编辑台。浏览时少打扰，创作时让“证据”和“自己的角度”同屏；快速短推与深挖选题并列。

## 界面分工与示意

**X 原帖：** 操作区附近只有保存按钮与一枚轻量“命中”标签。点击标签展示命中原因、指标时间，以及“快速改写”“在侧栏查看”；不遮挡原帖正文或原生按钮。

**侧栏，360–480px：**

```text
┌──────────────────────────────────┐
│ Topic Hunter   正在捕获  [暂停]   │
│ 今日候选 12       [打开素材库 ↗] │
├──────────────────────────────────┤
│ [高互动] [小号] [全部]  [搜索]   │
│                                  │
│ □ 作者 · 发布时间       阅读 2.1万│
│   原帖正文，最多展示 3 行…       │
│   命中：回复 42 ≥ 20             │
│   [快速改写] [保存]              │
│                                  │
│ □ 作者 · 发布时间        点赞 160 │
│   ……                             │
├──────────────────────────────────┤
│ 已选 2 条           [深挖选题]   │
└──────────────────────────────────┘
```

点单帖“快速改写”进入同侧栏的短推编辑视图；多选后“深挖选题”进入选题视图。两条路径都有返回候选入口。侧栏不同时铺开长列表、编辑器与长提纲。

**快速短推编辑，360px：**

```text
┌──────────────────────────────────┐
│ ← 候选       快速改写            │
├──────────────────────────────────┤
│ 来源：@作者 · 查看原帖 ↗         │
│ 证据：点赞 160 · 回复 42         │
│ 原帖摘要，展开查看完整内容       │
├──────────────────────────────────┤
│ 我的观点或例子（可选）           │
│ [输入一个自己的判断…]            │
│ [生成短推] [复制改写提示词]       │
│                                  │
│ 可编辑短推                       │
│ [正文编辑区                     ] │
│ [复制稿件]      [删除草稿]       │
└──────────────────────────────────┘
```

点击“快速改写”立即打开空编辑区，可直接手写；API 已配置时才显示可用的“生成短推”。无 API、拒权或生成失败时，“复制改写提示词”仍可用；外部 AI 的结果由用户手动贴回正文编辑区。复制按钮只取编辑区正文，不复制来源/指标，也不自动打开 X。编辑内容本地恢复，不进入选题库；来源素材卡可显示“继续草稿”。生成中的取消、关闭后的中断状态与选题生成一致。

**全页工作台：** 宽屏三栏为导航约 200px、素材列表弹性、证据/编辑详情约 380px；顶部搜索与筛选常驻。小于 960px 切为导航收起、列表与详情二选一。主导航只有“素材库”“选题库”“设置”；快速稿从素材详情或侧栏“继续草稿”进入，不占一个选题库分类。选题库用状态标签筛选，详情可直接编辑、复制、导出。

## 设计 Token

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--surface-canvas` | `#F5F7FB` | `#111827` | 页面背景 |
| `--surface-panel` | `#FFFFFF` | `#1F2937` | 卡片与侧栏 |
| `--text-primary` | `#182230` | `#F3F4F6` | 正文 |
| `--text-muted` | `#526071` | `#B9C3D0` | 次要信息 |
| `--accent` | `#315CF5` | `#8AA4FF` | 主操作与焦点 |
| `--border` | `#DDE3EC` | `#374151` | 分隔线 |
| `--success` | `#127D5D` | `#59D3A8` | 保存/完成 |
| `--warning` | `#A05A00` | `#F3BB65` | 缺失/异常 |
| `--signal` | `#D7FB70` | `#C8E866` | 小面积编号贴纸与品牌标记 |

- 8px 间距体系：4/8/16/24/32px；内容卡片 8px 圆角；按钮 8px 圆角；边框 1px。
- 正文 14px、行高 1.5；标题 18/24px；指标 12px，但不只靠字号或颜色表达意义。
- 页面默认跟随系统深浅主题，用户可选浅色/深色；颜色对比与焦点可见性在实现时用实际组件验证。原帖标签同时用文字与形状表达，不仅靠颜色。
- 图标用统一线性风格；动效只用于状态切换和保存反馈，遵循 `prefers-reduced-motion`。
- 当前界面以蓝色信号线、青柠编号贴纸、正文无衬线与编辑标题衬线字形成识别度；青柠只承担点缀，不替代状态文字。
- 品牌标识采用[选中短句](../../brand/README.md)：钴蓝捕获框包围三条内容线，青柠高亮被选中的一句；与原帖捕获行为直接关联。生产图标提供 16/32/48/128px 四档。

## D-S-T-E 体验闭环

| 步骤 | 本项目落实方式 | 验证 |
|---|---|---|
| 诊断 | 观察新用户能否分清“高互动候选”“已保存”“已采用”；记录超过 3 秒的停顿点 | 盲测 3 人完成浏览到选题流程，记录误解与回退 |
| 简化 | 首次默认预设可用；“单帖→快速改写→复制”最多 2 次主要操作，深挖路径“选素材→生成→保存”最多 3 次；复杂规则留设置页 | 分别在有/无 API 环境按点击记录核对 |
| 翻译 | 标签写“命中：回复 42 ≥ 20”，增长写“这两次看到之间新增”；错误提示给恢复动作 | 不出现无解释的“爆款分”“流速异常”等文案 |
| 升温 | 保存轻量反馈、AI 生成可取消、新候选不打断阅读；耗时超过 3 秒说明正在处理与可取消 | 键盘、慢网络、失败和取消路径均可完成 |

## 状态、键盘与响应式

- **加载**：列表使用原位骨架；生成显示已选条数、目标主机与取消按钮。不承诺无法准确预测的剩余时间。
- **空**：首次采集、筛选无结果、快速稿正文为空、选题库为空分别给行动入口；正文为空时“复制稿件”禁用。
- **错误**：采集、存储、导入、AI 网络、权限拒绝使用不同文案；保留用户已选输入，给重试或复制提示词。
- **成功**：保存、复制和导出用状态文本确认；复制成功文案为“已复制，可到 X 粘贴发布”，不暗示已经发布，不自动跳转或抢焦点。
- **禁用**：生成按钮在 0 条、>10 条或请求进行中禁用，旁边写出原因；缺密钥时仍启用“复制提示词”。
- **键盘**：原帖入口、列表、筛选、详情、编辑与保存按自然 Tab 顺序；Esc 关闭弹层并回到触发控件；所有图标按钮有可读名称。
- **尺寸**：侧栏 360px 与 480px，工作台 960px 上下、125%/200% 缩放分别检查横向溢出和控件触达。
