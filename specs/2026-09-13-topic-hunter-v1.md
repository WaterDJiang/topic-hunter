# Topic Hunter v1 产品规格

- 状态：有效，实施中；本地开发版已实现主要流程，真实 X 与 AI 验收未完成。
- 依据：用户确认公开开源、随浏览自动捕获、快速改写后复制到 X、AI 选题卡片、侧栏＋全页、API＋提示词双模式、简洁编辑台；本文件是 v1 行为唯一有效来源。
- 设计引用：[架构与契约](../doc/design/2026-09-13-extension-architecture.md)、[UI 与设计 Token](../doc/design/2026-09-13-ui-experience.md)、[开源调研](../doc/ref/2026-09-13-open-source-landscape.md)。

## 目标与边界

创作者正常浏览 X 时获得有来源、有指标的高表现短内容素材；适合即用的素材直接改成短推草稿，值得深挖的素材再生成选题卡。首版覆盖 Chrome 桌面版，不含账号系统、云同步、主动监控、插件代发或成稿保证。

成功标准分两层：M1–M3 验证采集、筛选和选题流程；真实发布后的阅读、评论、点赞变化需后续内容实验，不能由插件内测试推出。

## 核心流程

1. 首次启用，说明会在 `x.com` 页面观察公开帖子及指标；采集默认开启，可随时暂停。AI 发送数据需单独由用户点击触发。
2. 浏览首页、搜索、列表、个人主页和帖子详情；插件识别已收到的帖子，显示轻量命中标签与保存入口。
3. 侧栏查看候选和入选理由；全页按预设、作者、关键词、语言、时间及指标筛选、收藏、批量选取。每条素材并列提供“快速改写”和“深挖选题”。
4. **快速改写**：选一条素材，填写可选的自己的观点或例子；API 模式按点击生成一条可编辑短推，无 API 时复制改写提示词，也可手写。编辑后只复制稿件正文，由用户自行到 X 粘贴发布；不要求保存选题卡。
5. **深挖选题**：选中 1–10 条，使用 API 生成选题，或复制同结构提示词到外部 AI；编辑并保存选题卡。
6. 在选题库将卡片置为“待考虑／已采用／放弃”，复制或导出带原帖来源的 Markdown。

## 需求与验收

| ID | 行为与验收方式 |
|---|---|
| CAP-01 | 正常浏览五类指定页面时，捕获已收到的帖子数据；网络面板无插件追加的 X 数据请求，页面浏览与原生操作照常工作。 |
| CAP-02 | 每帖一个 `Post`，跨标签重复遇到时更新当前指标并保留观测历史；引用帖的文本与原帖正文分开。用脱敏样本覆盖普通、引用、截断、缺失与回落。 |
| CAP-03 | 每个指标可显示观测时间和数据来源；缺失显示“未知”。首次观测只能显示平均热度，两次有效观测才能显示带区间的新增阅读／小时。 |
| CAP-04 | 暂停后不再新增自动采集；恢复、切页、刷新和 Worker 重启后配置与已保存内容仍在。采集异常有可见提示与恢复动作。 |
| CAP-05 | 已打开的 X 页面若帖子响应未被观察到，仍从原帖可见 DOM 保存正文、原帖链接、发布时间与可读到的互动原始整数；仅在没有“显示更多”等截断提示时将正文视为完整。未知指标保持 `null`，不能伪造粉丝数。发现页同时显示已捕获总数与当前预设命中数，零命中时可一键查看全部。用真实 X DOM 结构的脱敏样本及浏览器扩展流程验证。 |
| FIL-01 | “短内容高互动”初值：完整正文 ≤280 可见字符、近 7 天，且阅读 ≥10,000／点赞 ≥100／回复 ≥20 任一满足；“小号发现”初值：同长度/时间，已知粉丝数 ≤10,000，且点赞 ≥30 或回复 ≥10。未知粉丝数不能命中小号预设。 |
| FIL-02 | 阈值可调整和恢复默认；“全部素材”不限热度。未命中的帖子也可手动保存；候选理由列出触发的具体字段和数值，不给不透明爆款分。 |
| FIL-03 | 未收藏、无选题或快速稿引用的自动候选在最后一次命中 30 天后可清理；收藏与被创作产物引用的素材保留。清理与删除在 UI 中可区分。 |
| QCK-01 | 单条素材可从原帖、侧栏和素材库进入“快速改写”，无需收藏或进入选题库；用户可直接手写，或填可选的个人观点/例子后显式触发 AI 改写。 |
| QCK-02 | API 模式产出一条可编辑短推，保留原帖证据与待核实提示；不虚构个人经历、评论或外部事实，不以近似复述代替自己的观点。无 API 或授权失败时可复制专用改写提示词，并把外部结果贴回编辑区。 |
| QCK-03 | “复制稿件”只复制编辑区正文，不附加原帖、指标或提示词；不调用 X 发帖接口、不自动打开或提交发帖框。复制后显示成功/失败反馈，不自动生成选题卡。未清除的编辑内容本地恢复，用户可删除；从原帖返回可继续编辑。 |
| TOP-01 | 一次选择 1–10 条；不足或超出时生成按钮禁用并说明原因。提示词含来源、指标、创作定位、事实边界。 |
| TOP-02 | 生成结果包含样本观察、3 个短推角度、2 个长文选题（各 3–5 点提纲）、来源和待核实事项。传播原因标为推测；不伪造作者个人经历、评论内容或外部事实。 |
| TOP-03 | 无 API 配置或站点权限被拒绝时仍可复制提示词。API 只在点击后发送所选素材；请求可取消；关闭页面再打开时显示中断，不自动重试。 |
| LIB-01 | 选题可编辑、改状态、复制和导出 Markdown，保存后可从来源回到原帖；源帖指标刷新不覆盖用户编辑。 |
| DAT-01 | JSON 备份带版本号，包含素材、观测、快速稿和选题，排除密钥；导入校验结构、按帖子 ID 与观测去重，不覆盖已编辑稿件或选题。损坏或未来版本文件给出明确错误，不部分写入。 |
| UX-01 | 360px 侧栏无横向溢出；“选素材→生成→保存”在已配置环境下不超过 3 次主要操作；键盘可完成同一路径，焦点与状态反馈符合 UI 设计。 |

## UI 状态与可见文案

- 采集：`正在捕获`、`已暂停`、`等待 X 页面`、`采集异常，重载 X 页面后重试`。
- 列表空态：`尚未采集素材` 与 `当前筛选没有命中` 分开；指标缺失使用 `未知`，不能显示 0。
- AI：`未配置接口，可复制提示词`、`生成中`、`已取消`、`上次生成已中断`、`接口请求失败，可重试或复制提示词`。重试是用户显式操作。
- 快速稿：`快速改写`、`复制改写提示词`、`复制稿件`、`已复制，可到 X 粘贴发布`、`复制失败，请手动选择正文`。提示词与稿件使用不同按钮，不能混淆。
- 保存：原地反馈，不抢焦点；新候选出现不自动移动列表或打开详情。
- 选题卡：`待考虑`、`已采用`、`放弃`；删除需区分删选题与删来源素材。

## 数据、安全与非功能需求

- 仅采集 X 页面已经加载的数据，不读取、保存或上传登录凭据，不自动滚动、刷新或触发额外 X 接口请求。
- 素材、观测和选题在本地 IndexedDB；设置在扩展存储。AI 接口和模型由用户配置；发送前能看到所选素材与目标主机；密钥不得进入备份、页面消息或日志。
- 10,000 条本地素材筛选 p95 ≤500ms；记录设备、浏览器版本、样本规模和测量方式。长时间运行与兼容性需在真实 X 页面验证。
- 语言由可获得的元数据或用户筛选提供；无法确定时标 `未知`。正文有图片但文本不足以解释主题时，AI 卡标注素材局限，不推测图片内容。
- 创作定位可选：领域、目标读者、输出语言、已有观点；默认中文输出，引用保留原文。提示词模式不解析外部 AI 返回结果。
- 快速稿与选题卡为不同产物；快速稿的当前编辑内容存本地，保留来源帖子 ID，可继续编辑和手动删除，但不出现在选题库或选题 Markdown 导出。JSON 备份包含快速稿且不含密钥。来源帖子若因自动候选清理而仍被快速稿引用，须保留至快速稿删除。

## 组件与回归范围

- M1 建立采集观察、桥接、归一化、数据访问边界；M2 增加规则与侧栏/全页 UI；M3 增加提示词、AI 客户端、快速稿和选题卡，不让业务规则嵌入 React 组件。
- 共享卡片或 Token 改动回归侧栏、素材库、快速稿与选题库；采集结构改动回归五类页面、引用帖与指标缺失；AI 改动回归快速改写及选题在有/无配置、拒绝授权、失败、取消和重开时的行为。
- UI 状态、响应式、键盘与焦点的详细依据只在 [UI 设计](../doc/design/2026-09-13-ui-experience.md)维护。

## 验证门槛

- M1–M3 的单元、集成和人工验收按 [阶段计划](../doc/plan/2026-09-13-m0-m4-roadmap.md)执行，未运行的检查不可记为通过。
- 快速路径人工验收：从已捕获单帖进入编辑、复制可发正文不超过 2 次主要操作（生成 AI 稿时另计点击“生成”）；关闭并重开侧栏后编辑内容仍在，选题库无自动新增。复制成功不等于已在 X 发布。
- 选题质量由用户在至少 3 个主题上选取 20 组素材盲评；至少 14 组出现一个愿意继续写的角度，来源对应全部正确，虚构个人经历为 0。未做此评估前只报告功能完成，不声称效果达标。
